# Muhammad Adil, Portfolio

AI Commercials Expert | Seedance Video Ads. Next.js, Tailwind CSS and GSAP.

## Run locally

```bash
pnpm install
pnpm dev
```

## Where things live

- `src/data/profile.ts`: name, headline, and contact details (email, LinkedIn, EmailJS keys)
- `src/data/work.ts`: portfolio videos; files live in `public/work/ugc/` (`<slug>.mp4` plus a `<slug>.jpg` poster)
- `public/hero/`: the hero photo and illustration
